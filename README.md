# CS3_TallerTodoPantallas_EquipoChihuahua

**Nombre de la Materia:** CS3
**Nombre del Proyecto:** To-Do List Application
**Equipo:** Chihuahua
**Integrantes:**
* Mateo Valencia Ardila
* Laura Quintero Correa
* Juan Camilo Cabrera Roa

**Descripción:**
Este proyecto implementa una aplicación de lista de tareas (To-Do List) interactiva utilizando HTML, CSS y JavaScript puro. Permite agregar tareas, marcarlas como completadas y eliminarlas, manejando validaciones y actualización dinámica del DOM.

**Requerimientos:**
* HTML5
* CSS3 (Uso de Flexbox)
* Vanilla JavaScript (ES6+)
* No requiere frameworks ni dependencias externas.

**Instrucciones de compilación y ejecución:**
1. Clonar el repositorio.
2. Abrir el archivo `index.html` directamente en cualquier navegador web moderno.
